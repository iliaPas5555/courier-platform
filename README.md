# Курьерская платформа — план и статус

Два продукта на общем backend:
- **Приложение для курьеров** — регистрация (ФИО, телефон, фото, номер мед. книжки, номер велосипеда), отметка выходов на смены, баланс и выплаты, чат (пересылается в Telegram-бота), форма обратной связи при опоздании/невыходе с фото/видео, уведомления.
- **Админ-панель** — расписание и выплаты по курьерам, ответы на вопросы, карточка курьера со всей историей.

## Архитектура (выбрана мной, можно менять)
- `backend/` — Node.js + TypeScript + Express + Drizzle ORM. Разработка на SQLite (без внешней БД), для продакшена (Render) переезд на Postgres — меняется только `src/db/client.ts`.
- `admin/` — веб-панель (React) для вас.
- `courier-app/` — веб-приложение для курьеров (React, PWA). На iPhone открывается как обычный сайт/добавляется на домашний экран. Для Android оборачивается через Capacitor в устанавливаемое приложение (реальный APK) — код общий, два раза ничего не пишем.
- `telegram-bot/` — отдельный процесс: пересылает ответы администратора из Telegram обратно в приложение курьера.

## Статус на сейчас
✅ `backend` — готов и проверен сквозным сценарием: регистрация курьера → выгрузка смены → чек-ин (в т.ч. авто-пометка LATE/NO_SHOW фоновой проверкой) → выплата → баланс → чат курьер↔админ → форма обратной связи с причиной → карточка курьера у админа.

⏳ Дальше по плану: `admin` (веб-панель), `courier-app` (PWA + Android-сборка), `telegram-bot`, деплой на Render.

## Как запустить backend локально
```bash
cd backend
npm install
npm run db:migrate
npm run db:seed -- --phone=+7XXXXXXXXXX --password=... --name="Ваше имя"
npm run dev
```
API поднимется на `http://localhost:4000` (см. `docs/API.md`).
